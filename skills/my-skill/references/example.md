# Referensi contoh

File di `references/` dibaca skill hanya saat dibutuhkan, jadi `SKILL.md` tetap ringkas. Taruh di sini hal yang panjang atau jarang dipakai: tabel, daftar aturan rinci, contoh tambahan.

## Batas panjang

| Teks asli | Inti | Butir |
|---|---|---|
| Di bawah dua kalimat | Tidak dirangkum | Tidak ada |
| Satu paragraf | Satu kalimat | Tiga |
| Beberapa halaman | Satu kalimat | Tiga, masing-masing satu kalimat |
