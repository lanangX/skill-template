# Code of Conduct

Kami ingin komunitas di sekitar proyek ini ramah, aman, dan membantu, sama seperti tujuan skill-nya.

## Standar

Perilaku yang kami harapkan:

- Bersikap sopan dan menghargai, termasuk saat tidak setuju.
- Mengkritik ide dan hasil kerja, bukan orangnya.
- Membantu pemula tanpa menggurui.
- Menerima umpan balik dengan lapang dada.

Perilaku yang tidak diterima:

- Pelecehan, hinaan, ancaman, atau diskriminasi dalam bentuk apa pun.
- Membagikan data pribadi orang lain tanpa izin.
- Spam, promosi yang tidak relevan, atau mengejar engagement di issue dan pull request.

## Penegakan

Pemelihara berhak mengedit, menghapus, atau menutup komentar, issue, dan kontribusi yang melanggar standar ini, dan memblokir pelanggar berulang. Laporkan pelanggaran lewat tab Security repo ini (Private vulnerability reporting) dengan judul yang jelas, atau hubungi pemelihara lewat profil GitHub mereka.

## Rujukan

Dokumen ini diadaptasi secara ringkas dari semangat [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
